การเชื่อมต่อ ROS 2 Agent & Topics

วิธีรัน micro-ROS Agent บน Linux (Ubuntu 22.04 / 24.04), การใช้ Docker และคำสั่งทดสอบรับส่ง Topic

1. การติดตั้งและรัน micro-ROS Agent

micro-ROS Agent ทำหน้าที่เป็นตัวแปลงสัญญาณระหว่าง XRCE-DDS ของ ESP32 ไปยังเครือข่าย ROS 2 DDS

วิธีที่ 1: รันผ่าน Docker (แนะนำ - ง่ายและเร็วที่สุด)

สำหรับ ROS 2 Humble (Ubuntu 22.04) ผ่านพอร์ต Serial USB:

docker run -it --rm -v /dev:/dev --privileged --net=host microros/micro-ros-agent:humble serial --dev /dev/ttyUSB0 -b 115200

สำหรับสื่อสารผ่าน Wi-Fi UDP (พอร์ต 8888):

docker run -it --rm --net=host microros/micro-ros-agent:humble udp4 --port 8888

วิธีที่ 2: สร้างและคอมไพล์จาก Colcon Workspace

# ติดตั้ง Dependencies
source /opt/ros/humble/setup.bash
mkdir -p ~/microros_ws/src
cd ~/microros_ws/src
git clone -b humble https://github.com/micro-ROS/micro_ros_setup.git
cd ~/microros_ws
rosdep update && rosdep install --from-paths src --ignore-src -y
colcon build
source install/local_setup.bash

# สร้าง Agent
ros2 run micro_ros_setup create_agent_ws.sh
ros2 run micro_ros_setup build_agent.sh
source install/local_setup.bash

# รัน Agent เชื่อมต่อบอร์ด RB_Nexus
ros2 run micro_ros_agent micro_ros_agent serial --dev /dev/ttyUSB0 -b 115200

2. คำสั่งตรวจสอบในระบบ ROS 2 (Verification Commands)

เปิด Terminal ใหม่บนเครื่องคอมพิวเตอร์ที่รัน ROS 2:

ตรวจดูโหนดและหัวข้อ (Nodes & Topics)

# รายชื่อ Nodes
ros2 node list
# ผลลัพธ์ที่ควรพบ: /rb_nexus_node

# รายชื่อ Topics
ros2 topic list
# ผลลัพธ์:
# /rb_nexus/chatter
# /rb_nexus/led_cmd
# /cmd_vel
# /joint_states
# /odom
# /battery_state

ทดสอบส่งคำสั่งขับเคลื่อนหุ่นยนต์ (/cmd_vel)

ส่งคำสั่งให้หุ่นยนต์วิ่งตรงด้วยความเร็ว 0.2 เมตร/วินาที:

ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.2, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"

ควบคุมผ่านคีย์บอร์ดด้วยแพ็กเกจ Teleop Twist Keyboard:

ros2 run teleop_twist_keyboard teleop_twist_keyboard

อ่านค่าข้อมูลเซนเซอร์ (Echo Topics)

# อ่านค่าพัลส์เอนโค้ดเดอร์
ros2 topic echo /joint_states

# ตรวจวัดแรงดันไฟแบตเตอรี่
ros2 topic echo /battery_state
