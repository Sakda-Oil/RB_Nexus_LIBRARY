ROS 2 Agent และ Topics

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

Agent (ตัวอย่าง Jazzy)

docker run -it --rm --net=host microros/micro-ros-agent:jazzy udp4 --port 8888
# Serial: ส่งผ่านอุปกรณ์ USB ให้ container ก่อน
docker run -it --rm --device=/dev/ttyUSB0 microros/micro-ros-agent:jazzy serial --dev /dev/ttyUSB0 -b 115200

เลือก transport ให้ตรงกับ sketch; บน Windows/WSL ต้องจัดการ USB forwarding หรือใช้ UDP และอนุญาต firewall ตามเครือข่ายจริง

ทดสอบคำสั่ง

ros2 topic list
ros2 topic echo /rb_nexus/imu
ros2 topic pub --rate 10 /rb_nexus/motor/1/cmd std_msgs/msg/Int16 "{data: 80}"
ros2 topic pub --once /rb_nexus/emergency_stop std_msgs/msg/Bool "{data: true}"

Topic emergency_stop อยู่ในตัวอย่าง 15; คำสั่ง motor/1 ควบคุม M1 ตรวจสถานะฮาร์ดแวร์บอร์ดของคุณก่อนใช้งานจริง ตัวอย่าง 08/09/15 หยุดเมื่อขาดคำสั่ง 500 ms

Topicชนิด / หน่วย
/rb_nexus/imusensor_msgs/Imu; m/s² และ rad/s; orientation ไม่รายงาน
/rb_nexus/analogInt32MultiArray; ADC A1..A8
/rb_nexus/encoder/1Int32; ticks
/rb_nexus/motor/1/cmdInt16; -255..255
/rb_nexus/batteryBatteryState; ต้องตั้ง divider ตามวงจรจริง

IMU ไม่ publish เมื่อ accel/gyro เก่าเกิน 500 ms; timestamp ใช้ Agent time เมื่อ sync สำเร็จ ค่า orientation_covariance[0] = -1 ตามรูปแบบ ROS
