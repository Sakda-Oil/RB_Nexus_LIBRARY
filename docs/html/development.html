การพัฒนา

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

ซอร์สหลักอยู่ใน libraries/RB_Nexus/src; RB_Nexus_IMU.cpp รวมไดรเวอร์ IMU และ RB_Nexus_MicroROS.h เป็น helper สำหรับ ROS โดยใช้ dependency จริง

python scripts/install_dependencies.py --config-file arduino-cli.yaml
python scripts/test_host.py
python scripts/build_package.py --repository Sakda-Oil/RB_Nexus_LIBRARY
python scripts/verify_package.py
python scripts/compile_examples.py --config-file arduino-cli.yaml

compile_examples.py ใช้ --library ชี้ซอร์สใน checkout เพื่อไม่เผลอทดสอบ library รุ่นเก่าที่ติดตั้งไว้ ใช้ --installed-library เมื่อต้องการตรวจ library ที่บรรจุในแพ็กเกจ

host tests ใช้ fake I2C/clock เพื่อทดสอบ logic; ไม่ใช่การจำลองไฟฟ้าหรือการรับรองเซนเซอร์จริง
