แนวทางการพัฒนาและการคอมไพล์แพ็กเกจ (Development Workflow)

โครงสร้างไฟล์ การสร้างแพ็กเกจ Arduino Board Manager และการใช้งาน arduino-cli แบบอัตโนมัติ

1. โครงสร้างโฟลเดอร์ของโปรเจกต์ (Repository Structure)

RB_Nexus_LIBRARY/
├── boards/esp32/             # คอนฟิกบอร์ด Arduino Board Definition
│   ├── boards.txt            # นิยามพารามิเตอร์คอมไพล์ esp32:RB_Nexus
│   ├── platform.txt          # เมนูและคอมไพเลอร์แฟล็ก
│   └── variants/RB_Nexus/    # ไฟล์ pins_arduino.h สำหรับ ESP32 WROOM-32
├── libraries/RB_Nexus/       # ซอร์สโค้ดไลบรารีหลัก
│   ├── library.properties    # เมทาดาทาของไลบรารี
│   ├── src/
│   │   ├── RB_Nexus.h        # คลาสและฟังก์ชันฮาร์ดแวร์
│   │   ├── RB_Nexus.cpp
│   │   ├── RB_Nexus_Pins.h   # แหล่งอ้างอิงพินพินเดี่ยว (Single Source of Truth)
│   │   └── RB_Nexus_MicroROS.h # รหัสเชื่อมต่อ micro-ROS
│   └── examples/             # สเก็ตช์ตัวอย่างกว่า 30 ตัวอย่าง
├── scripts/                  # สคริปต์อัตโนมัติของวิศวกร
│   ├── build_package.py      # รวมไฟล์เป็น .zip คำนวณ SHA-256 และสร้าง JSON index
│   ├── verify_package.py     # ตรวจสอบความถูกต้องของ index json
│   └── compile_all_examples.py # คอมไพล์ทดสอบทุกตัวอย่างด้วย arduino-cli
├── docs/                     # เอกสารเชิงเทคนิคและเว็บคู่มือ
└── package_RB_Nexus_index.json # ไฟล์ดัชนีสำหรับใส่ใน Preferences ของ Arduino IDE

2. สคริปต์สร้างแพ็กเกจ (build_package.py)

สคริปต์ Python สำหรับบิลด์ไฟล์ติดตั้ง Arduino Boards Manager อัตโนมัติ โดยจะดึงเวอร์ชันจากไฟล์ VERSION ทำการบีบอัด zip คำนวณ SHA-256 Checksum และขนาดไฟล์ byte size แล้วสร้างไฟล์ package_RB_Nexus_index.json:

python3 scripts/build_package.py --repository Sakda-Oil/RB_Nexus_LIBRARY
python3 scripts/verify_package.py

3. การใช้งาน arduino-cli เพื่อคอมไพล์และทดสอบ

นักพัฒนาสามารถคอมไพล์โค้ดได้โดยตรงจากเทอร์มินัลโดยไม่ต้องเปิด GUI:

# คอมไพล์สเก็ตช์ตัวอย่าง Blink ด้วยบอร์ด RB_Nexus
arduino-cli compile --fqbn RB_Nexus:esp32:RB_Nexus libraries/RB_Nexus/examples/Blink/Blink.ino

# คอมไพล์และอัปโหลดเข้าบอร์ด
arduino-cli compile --upload -p /dev/ttyUSB0 --fqbn RB_Nexus:esp32:RB_Nexus libraries/RB_Nexus/examples/FullBoardTest/FullBoardTest.ino
