คู่มือการติดตั้งแพ็กเกจบอร์ด RB_Nexus

ขั้นตอนการติดตั้งบอร์ดลงใน Arduino IDE 2.x และการตั้งค่าไดรเวอร์ในระบบปฏิบัติการต่างๆ

1. การเพิ่ม Additional Boards Manager URL

เปิดโปรแกรม Arduino IDE 2.x จากนั้นเข้าไปที่เมนู File > Preferences (หรือกด Ctrl + , บน Windows / Cmd + , บน macOS)

ในช่อง Additional Boards Manager URLs ให้วาง URL ดังต่อไปนี้:

https://raw.githubusercontent.com/Sakda-Oil/RB_Nexus_LIBRARY/main/package_RB_Nexus_index.json
ข้อแนะนำ: หากมี URL ของบอร์ดอื่นอยู่แล้ว ให้กดปุ่มหน้าต่างขวามือของช่องเพื่อเพิ่มบรรทัดใหม่ โดยไม่ต้องลบ URL เดิมออก

2. ติดตั้งบอร์ดผ่าน Boards Manager

  1. คลิกที่ไอคอน Boards Manager ที่แถบเครื่องมือด้านซ้าย (หรือเมนู Tools > Board > Boards Manager...)
  2. พิมพ์ค้นหาคำว่า RB_Nexus
  3. กดปุ่ม INSTALL เพื่อติดตั้งแพ็กเกจเวอร์ชันล่าสุด (0.2.0)
  4. รอจนกว่า Arduino IDE จะดาวน์โหลดคอมไพเลอร์และแพ็กเกจ core ESP32 จนเสร็จสมบูรณ์

3. การติดตั้งไดรเวอร์ USB-UART (CH340 Driver Setup)

บอร์ด RB_Nexus V0.1 ใช้ชิป CH340 สำหรับสื่อสารผ่านพอร์ต USB Type-C:

ระบบปฏิบัติการ Windows

  • โดยปกติ Windows 10 และ 11 จะติดตั้งไดรเวอร์ CH340 ให้อัตโนมัติเมื่อเสียบสาย USB
  • หากใน Device Manager พบเครื่องหมายตกใจสีเหลือง หรือไม่พบพอร์ต COM ให้ดาวน์โหลดไดรเวอร์ CH341SER.EXE จากผู้ผลิต WCH แล้วติดตั้ง

ระบบปฏิบัติการ Ubuntu / Linux

ระบบ Linux มีไดรเวอร์เคอร์เนล ch341 อยู่แล้ว แต่ต้องตั้งค่า Permission ให้ผู้ใช้เข้าถึงพอร์ต /dev/ttyUSB0 ได้:

# 1. เพิ่ม User ปัจจุบันเข้ากลุ่ม dialout
sudo usermod -a -G dialout $USER

# 2. ปิดบริการ brltty (Braille TTY) หากระบบตัดการเชื่อมต่อ CH340 อัตโนมัติ
sudo systemctl stop brltty-udev.service
sudo systemctl mask brltty-udev.service
sudo apt remove brltty -y

# 3. Log out และ Log in ใหม่เพื่อให้สิทธิ์มีผล

ระบบปฏิบัติการ macOS

  • พอร์ตของบอร์ดจะปรากฏในรูปแบบ /dev/cu.wchusbserial* หรือ /dev/cu.usbserial*
  • หากไม่ปรากฏพอร์ต ให้ติดตั้ง WCH CH34xVCPDriver สำหรับ macOS

4. การเลือกบอร์ดและทดสอบอัปโหลด

  1. ไปที่เมนู Tools > Board > RB_Nexus > RB_Nexus
  2. ไปที่เมนู Tools > Port แล้วเลือกพอร์ตที่เชื่อมต่อกับบอร์ด
  3. เปิดตัวอย่าง File > Examples > RB_Nexus > BoardInfo
  4. กดปุ่ม Upload (รูปลูกศรชี้ขวา)
  5. เปิด Serial Monitor ที่ความเร็ว 115200 baud เพื่อดูรายงานข้อมูลของบอร์ด
