การติดตั้ง

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

1. Boards Manager

เพิ่ม URL ด้านล่างใน Arduino IDE → Preferences → Additional Boards Manager URLs แล้วติดตั้ง RB_Nexus และเลือกบอร์ด RB_Nexus

https://raw.githubusercontent.com/Sakda-Oil/RB_Nexus_LIBRARY/main/package_RB_Nexus_index.json

2. ไลบรารีเซนเซอร์

ใน Library Manager ติดตั้ง MPU9250 โดย hideakitai 0.4.8 และ Adafruit BNO08x 1.2.7 พร้อม Adafruit BusIO และ Adafruit Unified Sensor ที่ระบบเสนอ ต้องติดตั้งทั้งสองไลบรารี เพราะไดรเวอร์ RB_Nexus รองรับการเลือกเซนเซอร์ขณะทำงาน

arduino-cli lib install "MPU9250@0.4.8" "Adafruit BNO08x@1.2.7"

3. ตรวจบอร์ด

เปิด Blink / BoardInfo แล้วอัปโหลด จากนั้นต่อ IMU และใช้ IMURaw เปิด Serial Monitor 115200 baud; ตัวอย่างทั่วไปไม่ต้องติดตั้ง micro-ROS

4. สำหรับ ROS เท่านั้น

ติดตั้ง micro_ros_arduino ตาม คู่มือ micro-ROS ก่อนเปิดตัวอย่างในโฟลเดอร์ micro_ros
