ตัวอย่างโค้ด

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

ตัวอย่างทั้งหมดอยู่ใน libraries/RB_Nexus/examples เปิดผ่าน Arduino IDE → File → Examples → RB_Nexus

  • Blink / BoardInfo / SerialEcho: เริ่มตรวจบอร์ด
  • IMURaw: เลือก MPU9250 หรือ BNO085 และอ่าน SI units
  • MotorTest / MotorPID: มอเตอร์และ PID
  • ServoTest / AnalogMCP3208 / EncoderTest: ทดสอบระบบย่อย
  • FullBoardTest / RB_Nexus_SelfTest: เครื่องมือช่วยตรวจบอร์ด
  • micro_ros/01..18: ตัวอย่าง ROS ต้องติดตั้ง dependency จริง

จำนวน sketches และผล compile ล่าสุดดู รายงานการทดสอบ ตัวอย่าง QC เดิมบางส่วนเป็นการสังเกตด้วยผู้ทดสอบ ไม่ใช่ผลรับรองฮาร์ดแวร์อัตโนมัติ
