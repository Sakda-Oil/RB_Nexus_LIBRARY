ขั้นตอนการทดสอบบอร์ด & การควบคุมคุณภาพ (QC Testing)

กระบวนการตรวจสอบฮาร์ดแวร์จริงก่อนส่งมอบ และการใช้งานสเก็ตช์ Self-Test เพื่อวินิจฉัยปัญหา

Interactive QC Checklist: บอร์ด RB_Nexus มีหน้าเว็บตรวจสอบคุณภาพแบบโต้ตอบได้ที่ไฟล์ docs/hardware_test_checklist.html สำหรับทีมผลิตใช้ติ๊กผลการทดสอบรายบอร์ด

1. โปรแกรมทดสอบตัวเองอัตโนมัติ (RB_Nexus_SelfTest)

สเก็ตช์ RB_Nexus_SelfTest.ino ออกแบบมาเพื่อรันตรวจจับฮาร์ดแวร์ทุกชิ้นเมื่อจ่ายไฟเข้าบอร์ด และรายงานผลสรุปทาง Serial Monitor ที่ 115200 baud:

ลำดับการทดสอบอัตโนมัติ (Auto Test Routine)

  1. ESP32 Chip ID & Internal Clocks: ตรวจสอบแกน Dual-Core 240 MHz และ Flash 4MB
  2. PCA9685 I2C Probe: ปิงแอดเดรส 0x40 หากไม่พบจะแจ้งเตือนว่าบัส I2C ขาด หรือชิปไม่มีไฟเลี้ยง
  3. MCP3208 SPI Self-Loop: อ่านค่าแรงดัน Floating หรือ Channel Reference บนบัส SPI
  4. Status LED Verification: สั่งกะพริบ LED GPIO 2 จำนวน 3 ครั้งเพื่อยืนยันว่าบอร์ดบูตพร้อมทำงาน
  5. Motor Safe Coast: สั่งเคลียร์รีจิสเตอร์ PWM ทุกช่องเป็น 0% เพื่อป้องกันมอเตอร์หมุนกระตุกตอนเปิดเครื่อง

2. สรุปผลการตรวจสอบฮาร์ดแวร์จริง (Physical Hardware Verification Summary)

ระบบย่อย (Subsystem) พิน / แอดเดรส ผลการทดสอบจริงบนฮาร์ดแวร์ สถานะวิศวกรรม
Status LED GPIO 2 กะพริบปกติ Active HIGH PASS
Digital I/O D4, D12, D14, D26, D27 ทดสอบทั้ง INPUT_PULLUP และ OUTPUT ผ่านทุกพิน PASS
Quadrature Encoders ENC1(36,39), ENC2(34,35), ENC3(32,33), ENC4(25,13) จับสัญญาณพัลส์ฮาร์ดแวร์อินเตอร์รัปต์ได้สมบูรณ์ทั้ง 4 ชุด PASS
Servo Outputs PCA9685 CH8 – CH15 สัญญาณพัลส์ 50 Hz ขับเซอร์โวเคลื่อนที่ได้ตามมุม 0–180° PASS
DC Motor 4 (M4) PCA9685 CH6, CH7 หมุนเดินหน้า-ถอยหลัง และหยุดได้สมบูรณ์ PASS
DC Motor 2 (M2) PCA9685 CH2, CH3 หมุนได้เพียงทิศทางเดียว (สัญญาณ CH3 หรือ H-Bridge ขาดวงจร) HARDWARE BUG
DC Motor 1, 3 (M1, M3) PCA9685 CH0,1 / CH4,5 มอเตอร์ไม่หมุน (ไม่มีสัญญาณออกจากไดรเวอร์ ต้องตรวจเช็คลายวงจร) NON-FUNCTIONAL
MCP3208 12-bit ADC SPI (MOSI=23, MISO=19, SCK=18, CS=5) การสื่อสาร SPI ปกติ อ่านค่า A1..A8 อยู่ระหว่างการเทียบสเกลวงจรจริง REVISION PENDING
CAN Bus & IMU Unassigned / Not Routed พอร์ตมีบนบอร์ด แต่ยังไม่มีข้อมูล Schematic และวงจรทรานซีฟเวอร์ชัดเจน LACK SCHEMATIC

3. รายการอุปกรณ์สำหรับห้องปฏิบัติการ QC

  • แหล่งจ่ายไฟปรับค่าได้ (DC Power Supply 12V 5A) พร้อมฟิวส์ป้องกันกระแสเกิน
  • สาย USB-C สำหรับต่อคอมพิวเตอร์และอัปโหลดโปรแกรม
  • มอเตอร์ทดสอบพร้อมเอนโค้ดเดอร์ 4 ชุด
  • RC เซอร์โวมอเตอร์มาตรฐาน (เช่น MG996R หรือ SG90) สำหรับทดสอบพอร์ตเซอร์โว
  • มัลติมิเตอร์ หรือออสซิลโลสโคปสำหรับวัดสัญญาณลอจิก PWM และ SPI
