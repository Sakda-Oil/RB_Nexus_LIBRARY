การทดสอบ

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

ทดสอบซอฟต์แวร์

python scripts/test_host.py
python scripts/build_package.py --repository Sakda-Oil/RB_Nexus_LIBRARY
python scripts/verify_package.py
python scripts/compile_examples.py --config-file arduino-cli.yaml

ใช้เครื่องมือและ dependency ตามคู่มือนักพัฒนา ผลที่ตรวจจริงบันทึกใน รายงานรุ่น 0.2.1

ตรวจบนบอร์ดก่อนใช้งาน

  1. ทดสอบ IMURaw กับ MPU9250 และ BNO085 แยกครั้ง: วางนิ่ง หมุนแต่ละแกน ตรวจหน่วยและทิศทาง
  2. ถอด IMU: freshness ต้องหมดอายุและ ROS หยุดส่งข้อมูลเก่า
  3. ยกล้อให้พ้นพื้น เปิด PID แล้ว motorStop(): ต้องไม่กลับมาหมุน
  4. ส่ง ROS motor command 10 Hz แล้วหยุดส่ง: มอเตอร์ต้องหยุดหลัง timeout ประมาณ 500 ms บวกเวลารอบ loop
  5. ทดสอบ emergencyStop: คำสั่งมอเตอร์ใหม่ต้องไม่ทำงานจน clear
  6. วัด servo pulse ด้วย oscilloscope และตรวจ PCA9685 เมื่อเปลี่ยนความถี่

software watchdog ต้องมี loop ที่เดินต่อได้ ไม่ทดแทนวงจรหยุดฉุกเฉินอิสระ
