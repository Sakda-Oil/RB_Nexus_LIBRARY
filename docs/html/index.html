RB_Nexus — คู่มือบอร์ดหุ่นยนต์

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

เริ่มจากติดตั้ง แล้วเลือกเซนเซอร์

ไลบรารีควบคุมมอเตอร์ PCA9685, Servo, MCP3208, Encoder และ IMU MPU6050 / MPU9250 / GY-BNO085 พร้อมตัวอย่าง micro-ROS ที่ใช้ไลบรารีจริง

1. ติดตั้ง · 2. ต่อ IMU · 3. ทดสอบ

สิ่งที่แก้ใน 0.2.1

  • อ่านข้อมูล IMU จริง พร้อมเวลาความสดของข้อมูล
  • หยุดมอเตอร์แล้วปิด PID; คำสั่ง ROS หมดอายุใน 500 ms
  • ชื่อ API และตัวอย่างในคู่มือตรงกับซอร์ส
  • เลิกใช้ micro-ROS fallback ที่แสร้งคืนค่าสำเร็จ
การคอมไพล์ผ่านไม่ยืนยันการต่อสายหรือผลฮาร์ดแวร์จริง โปรดดูผลทดสอบและตรวจบอร์ดของคุณตามขั้นตอน
