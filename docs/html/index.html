RB_Nexus

ESP32 Robotics Controller & micro-ROS Embedded Platform • Redbrick Robotics

ฮาร์ดแวร์เป้าหมาย (Hardware Target): โมดูล ESP32 NodeMCU ESP-WROOM-32 Dual Core 240 MHz, 38-Pin, พร้อมชิปแปลง USB-UART CH340 และพอร์ต USB Type-C

ภาพรวมคุณสมบัติเด่น (Features)

🚗 ขับมอเตอร์ DC 4 ช่อง

ควบคุมมอเตอร์ 4 ตัว (H-Bridge) ผ่านชิป PCA9685 I2C พร้อมระบบป้องกันการกระชากกลับทิศทาง (Reversal Dead-Time) และ Emergency Stop ทันที

🔄 Quadrature Encoder 4 ช่อง

นับพัลส์ความเร็วสูงด้วย ESP32 GPIO Interrupt แบบ 2x Quadrature คำนวณ RPM แบบ Real-time และทิศทางการหมุน

📊 อนาล็อก 12-bit 8 ช่อง

ชิป MCP3208 12-bit ADC อ่านค่าความละเอียด 0–4095 ผ่านบัส SPI ความเร็ว 1 MHz แม่นยำ แยกอิสระจาก internal ADC

🦾 เซอร์โว 8 ช่อง (50 Hz)

ขับ RC Servos 8 ช่อง (ช่อง 8 ถึง 15) ผ่าน PWM ความถี่ 50 Hz จาก PCA9685 ปรับมุม 0°–180° ได้อย่างราบเรียบ

📡 การเชื่อมต่อ Wi-Fi & Bluetooth

Wi-Fi 2.4 GHz 802.11 b/g/n และ Bluetooth Classic 4.2 BR/EDR ในตัว พร้อมระบบ Auto-reconnect แบบ Non-blocking

🤖 micro-ROS & ROS 2 Native

เชื่อมต่อระบบหุ่นยนต์ ROS 2 (Humble & Jazzy) ผ่าน Serial USB หรือ Wi-Fi UDP พร้อม State Machine และ Safety Watchdog

สเปคบอร์ดสรุป (Summary Specifications)

รายการ (Item) รายละเอียด (Specification)
ไมโครคอนโทรลเลอร์ (MCU) ESP32-WROOM-32, Xtensa Dual-Core 32-bit LX6, 240 MHz
หน่วยความจำ Flash 4 MB SPI Flash (DIO Mode, 40 MHz)
แรงดันไฟเลี้ยงบอร์ด (Vin) DC 6–24 V (พร้อมวงจรลดแรงดัน Step-down จ่ายไฟเลี้ยงระบบ)
ชิปเชื่อมต่อคอมพิวเตอร์ (USB-UART) WCH CH340 พร้อมวงจร Auto-reset สำหรับอัปโหลดโค้ดอัตโนมัติ
ชิปควบคุม PWM (มอเตอร์ & เซอร์โว) NXP PCA9685 (16-Channel 12-bit I2C, Address 0x40)
ชิปอ่านสัญญาณอนาล็อก (ADC) Microchip MCP3208 (8-Channel 12-bit SPI ADC)
การรองรับ ROS 2 micro-ROS Humble (Ubuntu 22.04) และ Jazzy (Ubuntu 24.04)

เริ่มต้นใช้งานอย่างรวดเร็ว (Quick Start)

  1. ติดตั้งแพ็กเกจผ่าน Boards Manager: เพิ่ม URL ใน Arduino IDE แล้วค้นหา RB_Nexus
  2. เลือกบอร์ด: Tools > Board > RB_Nexus > RB_Nexus
  3. เปิดตัวอย่างทดสอบรวม: File > Examples > RB_Nexus > FullBoardTest
  4. กด Upload และเปิด Serial Monitor ที่ 115200 baud เพื่อเริ่มทดสอบ
