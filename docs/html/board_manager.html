Boards Manager

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

แพ็กเกจ RB_Nexus สร้างจาก Arduino-ESP32 core 3.3.10 พร้อม variant rb_nexus และ library ภายใน เลขรุ่นแพ็กเกจ 0.2.1 แยกจากเลขรุ่น core

ค่าเริ่มต้น: ESP32, flash 4 MB, DIO, flash clock 40 MHz, upload 115200 ตรวจขนาด flash จริงก่อนเลือก 8 MB

Library dependencies ของ IMU ต้องติดตั้งผ่าน Library Manager เพิ่ม แม้บอร์ดติดตั้งแล้ว ดู การติดตั้ง

ไฟล์ index ต้องอ้าง archive ที่มีอยู่จริงและ checksum ตรงกัน; workflow จะอัปเดต index หลังเผยแพร่ asset สำเร็จ
