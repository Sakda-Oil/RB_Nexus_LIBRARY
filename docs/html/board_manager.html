โครงสร้าง Board Package & FQBN

รายละเอียดเมนู Tools, พารามิเตอร์การคอมไพล์ และการใช้งานผ่าน arduino-cli

1. Fully Qualified Board Name (FQBN)

รหัสระบุบอร์ดมาตรฐานสำหรับ Arduino CLI และระบบ Build อัตโนมัติคือ:

RB_Nexus:esp32:rb_nexus

2. ค่าพารามิเตอร์เริ่มต้นในเมนู Tools (Default Board Options)

พารามิเตอร์ (Option) ค่าเริ่มต้น (Default) คำอธิบาย
Board RB_Nexus ชื่อบอร์ดหลักที่แสดงในเมนู
Upload Speed 115200 ความเร็วอัปโหลดมาตรฐาน เสถียรสูงสุดกับชิป CH340
CPU Frequency 240MHz (WiFi/BT) ความเร็วสัญญาณนาฬิกาซีพียู Xtensa Dual-Core
Flash Frequency 40MHz ความเร็วบัส SPI Flash เพื่อความเสถียรของโมดูล WROOM-32
Flash Mode DIO Dual I/O SPI Mode
Flash Size 4MB (32Mb) ขนาดความจุ Flash มาตรฐานของโมดูล WROOM-32 (ปรับเป็น 8MB/16MB ได้)
Partition Scheme Default 4MB with spiffs 1.2MB App, 1.5MB SPIFFS
Core Debug Level None ปิดข้อความดีบักภายในเพื่อเพิ่มความเร็วในการรัน
PSRAM Disabled โมดูล ESP32-WROOM-32 ไม่มีชิป PSRAM ภายนอก

3. การใช้งานผ่าน Arduino CLI

สามารถสั่งคอมไพล์และอัปโหลดโค้ดผ่าน Terminal ได้โดยตรง:

# 1. ตรวจสอบบอร์ดที่เชื่อมต่อ
arduino-cli board list

# 2. คอมไพล์โปรแกรม
arduino-cli compile --fqbn RB_Nexus:esp32:rb_nexus libraries/RB_Nexus/examples/BoardInfo

# 3. อัปโหลดลงบอร์ด (ระบุพอร์ตที่ตรวจพบ)
arduino-cli upload -p /dev/ttyUSB0 --fqbn RB_Nexus:esp32:rb_nexus libraries/RB_Nexus/examples/BoardInfo

# 4. เปิดดูข้อความ Serial
arduino-cli monitor -p /dev/ttyUSB0 -c baudrate=115200
