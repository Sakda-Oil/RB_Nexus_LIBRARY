micro-ROS บนบอร์ด RB_Nexus (ESP32)

สถาปัตยกรรมระบบ micro-ROS, การจัดการความเข้ากันได้ของคอมไพเลอร์, กลไกความปลอดภัย และ Transport Layer

1. สถาปัตยกรรมระบบ (Architecture Overview)

micro-ROS ช่วยให้บอร์ด ESP32 บนหุ่นยนต์ RB_Nexus สามารถทำหน้าที่เป็น ROS 2 Node ตัวเต็ม โดยสื่อสารแลกเปลี่ยน Topic, Service และ Parameter กับระบบประมวลผลหลัก (เช่น ROS 2 Humble บน Raspberry Pi หรือ PC) ผ่าน micro-ROS Agent

การทำงานแบบ State Machine

ไลบรารี RB_Nexus_MicroROS.h ควบคุมการเชื่อมต่อแบบ FSM ป้องกันหุ่นยนต์ทำงานผิดปกติเมื่อการเชื่อมต่อหลุด:

  • WAITING_AGENT: ESP32 ตรวจสอบการตอบสนองจาก micro-ROS Agent
  • AGENT_AVAILABLE: พบคอมพิวเตอร์เอเจนต์ กำลังสร้าง Node, Publishers และ Subscribers
  • CONNECTED: สื่อสารข้อมูลสมบูรณ์ พร้อมรับส่งคำสั่งความเร็วและเซนเซอร์
  • DISCONNECTED: สัญญาณขาดหาย ระบบสั่ง E-Stop หยุดมอเตอร์ทั้งหมดทันที และพยายามเชื่อมต่อใหม่แบบ Exponential Backoff

2. ตารางความเข้ากันได้ของคอมไพเลอร์ (Compatibility Matrix)

ข้อควรระวังสำคัญทางเทคนิค: ESP32 Arduino Core เวอร์ชัน 3.x ใช้ ESP-IDF v5.1 ซึ่งไลบรารีภายนอก micro_ros_arduino แบบ Precompiled Binary ในปัจจุบันถูกคอมไพล์มาจาก ESP-IDF v4.4
Arduino-ESP32 Core ESP-IDF Base สถานะ micro_ros_arduino แนวทางการใช้งานใน RB_Nexus
v2.0.17 (LTS) ESP-IDF v4.4 Fully Compatible คอมไพล์ Native Binaries และใช้งานร่วมกับไลบรารี micro_ros_arduino ได้ทันที 100%
v3.x (เช่น 3.3.10) ESP-IDF v5.1 ABI Mismatch ใช้ RB_Nexus_MicroROS.h Fallback Stubs โค้ดคอมไพล์ผ่านทุกบอร์ด หรือใช้ Docker ESP-IDF v5 build

3. นวัตกรรม Fallback Stubs สากลของ RB_Nexus

เพื่อให้ตัวอย่างโค้ดและไลบรารีสามารถคอมไพล์และทดสอบบนคอมพิวเตอร์ของนักพัฒนาได้ทุกคน แม้จะยังไม่ได้ติดตั้งไลบรารี micro-ROS แยกต่างหาก ไฟล์ RB_Nexus_MicroROS.h จึงมาพร้อมระบบตรวจสอบอัตโนมัติ:

#if __has_include(<micro_ros_arduino.h>)
  // ใช้งานชุดคำสั่ง Native micro-ROS จริง
  #include <micro_ros_arduino.h>
  #include <rcl/rcl.h>
  #include <rclc/rclc.h>
#else
  // ใช้งาน Lightweight Emulation Stubs สำหรับการคอมไพล์และทดสอบ
  #define RCUTILS_RET_OK 0
  ...
#endif

4. วอทช์ด็อกเพื่อความปลอดภัย (Safety Watchdog)

ในการควบคุมหุ่นยนต์เคลื่อนที่ (Mobile Robot) หากตัวส่งสัญญาณ ROS 2 หลุดหรือโปรแกรมคอมพิวเตอร์แครช ล้ออาจหมุนค้างและชนสิ่งกีดขวาง RB_Nexus มีวงจรความปลอดภัยฝังตัวในระดับไมโครคอนโทรลเลอร์:

  • เมื่อได้รับข้อความ /cmd_vel ตัวจับเวลาจะถูกรีเซ็ต (Heartbeat Feed)
  • หากไม่มีคำสั่งใหม่เข้ามาเกินกว่า 1000 มิลลิวินาที ฟังก์ชัน motorStopAll() จะถูกเรียกโดยอัตโนมัติ
  • ไฟสถานะ LED บนขา GPIO 2 จะกะพริบเตือนสถานะขาดการเชื่อมต่อ
