อาการตรวจ/แก้
MPU9250.h / Adafruit_BNO08x.h not foundติดตั้งทั้งสองไลบรารีและ dependencies ใน Library Manager
micro_ros_arduino.h not foundติดตั้ง Jazzy snapshot ตามคู่มือ ROS; ไม่มี fallback จำลองแล้ว
IMU not foundตรวจรุ่นชิปจริง, address, 3.3V logic, GND, I2C mode; ตรวจ WHO_AM_I ให้ตรงกับรุ่นที่เลือก
IMU ไม่มีข้อมูลใหม่เรียก update() บ่อย ๆ ตรวจสายและ pull-up; ลอง 100 kHz; retry imuBegin หลังแก้สาเหตุ
มอเตอร์ไม่หมุนตรวจไฟกำลัง, emergency latch และ PCB ของ M1/M2/M3 ตามรายงานเดิม
ROS ไฟกะพริบและหยุดสร้าง entities ไม่สำเร็จ ตรวจ Agent/transport แล้ว restart บอร์ด
Boards Manager ดาวน์โหลด 404ตรวจว่า release asset ตาม index ถูกเผยแพร่แล้ว; ห้ามแก้ checksum โดยเดา
