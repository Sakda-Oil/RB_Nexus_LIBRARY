คู่มือแก้ปัญหาทางเทคนิค (Troubleshooting Guide)

วิเคราะห์อาการ สาเหตุ วิธีตรวจเช็ค และแนวทางแก้ไขสำหรับฮาร์ดแวร์และซอฟต์แวร์

ตารางวิเคราะห์ปัญหา (Symptom & Solution Matrix)

1. ปัญหาการอัปโหลดโค้ด: "A fatal error occurred: Failed to connect to ESP32"

สาเหตุ: คอมพิวเตอร์ไม่พบพอร์ต Serial หรือชิป ESP32 ไม่เข้าสู่โหมด Bootloader อัตโนมัติ

  • วิธีตรวจเช็ค: ตรวจดูใน Device Manager (Windows) หรือรันคำสั่ง ls /dev/cu.usb* (macOS/Linux) ว่ามีพอร์ต CH340 ปรากฏหรือไม่
  • วิธีแก้ไข:
    1. ติดตั้งไดรเวอร์ CH340/CH341 USB-to-UART สำหรับระบบปฏิบัติการของคุณ
    2. เปลี่ยนสาย USB เป็นสาย Data คุณภาพสูง (หลีกเลี่ยงสายชาร์จโทรศัพท์แบบไม่มีสาย Data)
    3. ขณะกด Upload ใน Arduino IDE เมื่อขึ้นข้อความ Connecting...... ให้กดปุ่ม BOOT บนบอร์ดค้างไว้ 1-2 วินาทีแล้วปล่อย

2. มอเตอร์ M1 และ M3 ไม่หมุน หรือ M2 หมุนทางเดียว

สาเหตุ: ในฮาร์ดแวร์บอร์ดรุ่น V0.1 มีความผิดพลาดเชิงวงจรที่ไดรเวอร์มอเตอร์

  • มอเตอร์ M4: ทำงานได้สมบูรณ์ทั้งสองทิศทาง
  • มอเตอร์ M2: ลายวงจรสัญญาณ CH3 (IN2) ของ PCA9685 อาจขาดหรือไอซีขับเสียหาย ทำให้หมุนได้ทิศทางเดียว
  • มอเตอร์ M1 และ M3: วงจรลอจิกหรือไฟเลี้ยงของชุดขับ H-Bridge ชุดแรกไม่ทำงาน
  • วิธีแก้ไขเบื้องต้น: ใช้บอร์ดขับมอเตอร์ภายนอกต่อรับสัญญาณ PWM จากช่องเซอร์โว 8–15 หรือรอการแก้ไข PCB ในรุ่น Revision 0.2

3. I2C Error: "PCA9685 Not Found at 0x40"

สาเหตุ: ขาสัญญาณ SDA (GPIO 21) หรือ SCL (GPIO 22) ไม่มีตัวต้านทาน Pull-up หรือชิป PCA9685 ไม่มีไฟเลี้ยง 5V

  • วิธีตรวจเช็ค: อัปโหลดสเก็ตช์ I2CScanner.ino ดูว่าตรวจพบอุปกรณ์แอดเดรสใดบ้าง
  • วิธีแก้ไข:
    1. ตรวจสอบว่าได้ต่อไฟเลี้ยงแบตเตอรี่เข้าขั้ว DC Input แล้วหรือไม่ (ชิป PCA9685 ต้องการไฟเลี้ยง 5V จากวงจร Buck Converter)
    2. ตรวจสอบตัวต้านทาน Pull-up 4.7k บนสาย SDA/SCL

4. ค่าอนาล็อก MCP3208 แกว่ง หรืออ่านได้ 0 / 4095 ตลอดเวลา

สาเหตุ: ขาสัญญาณ SPI Chip Select (GPIO 5) ไม่ต่อกับขา CS ของ MCP3208 หรือขาอนาล็อกไม่ได้ต่อวงจรทำให้ลอย (Floating)

  • วิธีตรวจเช็ค: นำสายจัมเปอร์ต่อพอร์ต A1 ลงกราวด์ (GND) ต้องอ่านได้ 0 และต่อเข้าไฟ 3.3V ต้องอ่านได้ประมาณ 4095
  • วิธีแก้ไข: หากพอร์ตลอยให้ต่อตัวต้านทาน Pull-down 10k หรือต่อสัญญาณจากเซนเซอร์ที่มีเอาต์พุตแรงดันแน่นอน

5. micro-ROS Agent เชื่อมต่อไม่ติด (Agent Not Found)

สาเหตุ: Baud rate ไม่ตรงกัน พอร์ต Serial ถูกโปรแกรมอื่นครอบครอง หรือสิทธิ์พอร์ตของระบบปฏิบัติการ

  • วิธีตรวจเช็ค: ปิดโปรแกรม Serial Monitor ของ Arduino IDE ก่อนสั่งรัน Docker หรือ Agent
  • วิธีแก้ไขบน Linux: 
    # ให้สิทธิ์อ่านเขียนพอร์ต USB
sudo chmod 666 /dev/ttyUSB0
# หรือเพิ่ม user เข้า dialout group
sudo usermod -aG dialout $USER
