API Reference

คู่มือฟังก์ชัน คลาส และคำสั่งทั้งหมดของไลบรารี RB_Nexus สำหรับ ESP32

Header File: เพียงแค่ใส่ #include <RB_Nexus.h> ในโปรเจกต์ของคุณ ระบบจะทำการ include คอนฟิกขา คลาสฮาร์ดแวร์ และสร้างอินสแตนซ์สากล Nexus ให้ใช้งานได้ทันที

1. ฟังก์ชันระบบหลัก (System Core)

Nexus.begin()

เริ่มต้นระบบบัส I2C, SPI, ชิป PCA9685, ตั้งค่าสถานะเริ่มต้นของมอเตอร์และขา I/O ทั้งหมด

bool begin(unsigned long baud = 115200);

พารามิเตอร์: baud (ค่าเริ่มต้น 115200) - ความเร็ว Serial Monitor

คืนค่า: true หากพบชิป PCA9685 บนบัส I2C ที่แอดเดรส 0x40 สำเร็จ

Nexus.printBoardInfo()

พิมพ์ข้อมูลสรุปฮาร์ดแวร์ เวอร์ชันไลบรารี สเปคไมโครคอนโทรลเลอร์ ESP32 และผังขาไปยัง Serial Monitor

void printBoardInfo();

Nexus.watchdogFeed() & enableWatchdog()

เปิดใช้งานและรีเซ็ตซอฟต์แวร์วอทช์ด็อกเพื่อความปลอดภัย เมื่อหุ่นยนต์ขาดการสื่อสาร มอเตอร์ทั้งหมดจะหยุดหมุนอัตโนมัติ (E-Stop)

void enableWatchdog(uint32_t timeout_ms = 1000);
void watchdogFeed();
bool isWatchdogTriggered();

2. Status LED & Digital I/O

Nexus.setLED() & toggleLED()

ควบคุมไฟสถานะบนบอร์ด (ต่อกับ GPIO 2, Active HIGH)

void setLED(bool state);
void toggleLED();
void blinkLED(uint16_t on_ms, uint16_t off_ms);

3. ควบคุมดีซีมอเตอร์ (DC Motor Subsystem)

ควบคุมมอเตอร์ 4 ช่อง (M1..M4) ขับผ่านชิปขยายขา PWM PCA9685 พร้อมฟังก์ชันคำนวณ Reversal Dead-time ป้องกัน Shoot-through

Nexus.motorDrive()

void motorDrive(uint8_t channel, int16_t speed);

พารามิเตอร์:

  • channel: ช่องมอเตอร์ 1 ถึง 4 (ตรงกับ M1, M2, M3, M4)
  • speed: ความเร็วและทิศทาง ตั้งแต่ -100 (ถอยหลังเต็มที่) ถึง +100 (เดินหน้าเต็มที่), 0 คือหยุดหมุน (Coast)

Nexus.motorStop() & motorStopAll()

void motorStop(uint8_t channel);
void motorStopAll(); // สั่งตัดกำลังมอเตอร์ทั้งหมดทันที (E-Stop)

4. ควบคุมเซอร์โวมอเตอร์ (Servo Subsystem)

ควบคุม RC Servo ช่อง 8 ถึง 15 ความถี่ 50 Hz (20 ms period) ความละเอียด 12-bit จาก PCA9685

Nexus.servoWrite() & servoWriteMicroseconds()

void servoWrite(uint8_t channel, uint8_t angle);
void servoWriteMicroseconds(uint8_t channel, uint16_t us);

พารามิเตอร์:

  • channel: ช่องเซอร์โว 8 ถึง 15
  • angle: มุมองศา 0 ถึง 180
  • us: ความกว้างพัลส์ไมโครวินาที (ช่วงมาตรฐาน 500 ถึง 2500 us)

5. อินเตอร์รัปต์เอนโค้ดเดอร์ (Quadrature Encoders)

อ่านสัญญาณพัลส์ Quadrature (Phase A, B) 4 ช่องสัญญาณ ด้วยฮาร์ดแวร์ GPIO Interrupt ของ ESP32

Nexus.encoderInit() & getEncoderCount()

void encoderInit(uint8_t channel);
int32_t getEncoderCount(uint8_t channel);
void resetEncoderCount(uint8_t channel);
float getEncoderRPM(uint8_t channel, uint16_t ppr = 330);

แชนแนล: 1 (GPIO 36, 39), 2 (GPIO 34, 35), 3 (GPIO 32, 33), 4 (GPIO 25, 13)

6. อนาล็อกภายนอก 12-bit (MCP3208 SPI ADC)

Nexus.analogReadMCP()

uint16_t analogReadMCP(uint8_t channel);
float analogReadVoltage(uint8_t channel, float vref = 3.3f);

พารามิเตอร์: channel: ช่องอนาล็อก 0 ถึง 7 (ตรงกับพอร์ต A1 ถึง A8)

คืนค่า: ค่าดิจิทัล 12-bit (0 ถึง 4095) หรือแรงดันไฟฟ้า (0.00V ถึง 3.30V)

7. ระบบควบคุมความเร็ว PID (Speed Control)

RB_Nexus_PID

class RB_Nexus_PID {
public:
  RB_Nexus_PID(float kp, float ki, float kd);
  void setTunings(float kp, float ki, float kd);
  void setTargetRPM(float target);
  int16_t compute(float current_rpm);
  void reset();
};

8. micro-ROS Subsystem

อินเทอร์เฟซสื่อสารระดับสูงระหว่าง RB_Nexus กับ ROS 2 สถาปัตยกรรม State-Machine ปลอดภัย

RB_Nexus_MicroROS

#include <RB_Nexus_MicroROS.h>

RB_Nexus_MicroROS uros;
uros.begin(115200);
uros.spinSome();
uros.isAgentConnected();
