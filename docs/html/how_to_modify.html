คู่มือการแก้ไขสำหรับฮาร์ดแวร์รอบถัดไป (How to Modify for Next Revision)

คำแนะนำทีละขั้นตอนสำหรับวิศวกรในการอัปเดตผังขา เพิ่มบอร์ด Revision ใหม่ และต่อขยายเซนเซอร์

Single Source of Truth: ผังขาทั้งหมดของโปรเจกต์ถูกรวมศูนย์ไว้ที่ไฟล์เดียวคือ libraries/RB_Nexus/src/RB_Nexus_Pins.h ทำให้ง่ายต่อการบำรุงรักษาและไม่เกิดข้อขัดแย้งของพิน

1. ขั้นตอนการเปลี่ยนหรือเพิ่มพินใน RB_Nexus_Pins.h

เมื่อมีการปรับเปลี่ยนเส้นทางลายวงจร (PCB Re-routing) บนบอร์ดรุ่นใหม่ ให้แก้ไขเฉพาะในไฟล์ RB_Nexus_Pins.h:

// ตัวอย่างการแก้ไขพินใน RB_Nexus_Pins.h
#define RB_PIN_CAN_TX      4    // ย้าย CAN TX ไปยัง GPIO 4
#define RB_PIN_CAN_RX      5    // ย้าย CAN RX ไปยัง GPIO 5

// หากพินใดยังไม่ได้ต่อวงจร ให้คงค่า RB_PIN_UNDEFINED (-1) ไว้เสมอ
#define RB_PIN_IMU_INT     RB_PIN_UNDEFINED

2. การเพิ่มการรองรับ Hardware Revision ใหม่ (เช่น Revision 0.2)

สถาปัตยกรรมของไลบรารีออกแบบระบบรองรับหลาย Revision ผ่าน Macro Switching ไว้เรียบร้อยแล้ว:

ขั้นตอนการประกาศ Revision 0.2

  1. เปิดไฟล์ RB_Nexus_Pins.h
  2. ประกาศ Revision ใหม่: 
    #define RB_NEXUS_REV_01    1
#define RB_NEXUS_REV_02    2

// เลือก Revision ปัจจุบัน
#ifndef RB_NEXUS_CURRENT_REV
#define RB_NEXUS_CURRENT_REV  RB_NEXUS_REV_02
#endif
  3. ใช้เงื่อนไขพรีโพรเซสเซอร์ #if (RB_NEXUS_CURRENT_REV == RB_NEXUS_REV_02) เพื่อกำหนดพินใหม่ โดยโค้ดของ V0.1 เดิมยังคงสามารถคอมไพล์ย้อนหลังได้ 100%

3. สิ่งที่ต้องแก้ไขบนแผ่นวงจรพิมพ์ (PCB Fix Checklist สำหรับ Revision 0.2)

  • แก้ไขวงจรขับมอเตอร์ M1 และ M3: ตรวจสอบขาสัญญาณ IN1/IN2 จากชิป PCA9685 ช่อง 0, 1, 4, 5 ว่าต่อเข้ากับ Gate ไดรเวอร์ของ H-Bridge สมบูรณ์หรือไม่ และตรวจสอบไฟเลี้ยง VCC/VMOT ของไดรเวอร์
  • แก้ไขมอเตอร์ M2: ตรวจสอบลายวงจรช่อง CH3 (IN2) ของ PCA9685 ที่ขาดหาย เพื่อให้หมุนกลับทางได้ครบสองทิศทาง
  • เพิ่ม CAN Transceiver IC: ติดตั้งไอซีแปลงระดับสัญญาณ CAN เช่น SN65HVD230 (3.3V) ต่อเข้ากับ GPIO ของ ESP32 เพื่อให้พอร์ต CAN ใช้งานได้จริง
  • ระบุตำแหน่งและไอซีเซนเซอร์ IMU ให้ชัดเจน: ระบุพิน I2C หรือ SPI สำหรับเซนเซอร์ 6-DOF (เช่น MPU6050 หรือ ICM-42688-P)

4. การเพิ่มไลบรารีเซนเซอร์ I2C หรือ SPI ตัวใหม่

ในการต่อขยายโมดูลภายนอกเพิ่มเติม เช่น จอ OLED หรือเซนเซอร์วัดระยะ ToF VL53L0X:

// ใช้บัส I2C ร่วมกับพินมาตรฐานของ RB_Nexus
#include <RB_Nexus.h>
#include <Adafruit_VL53L0X.h>

Adafruit_VL53L0X lox = Adafruit_VL53L0X();

void setup() {
  Nexus.begin(); // เริ่มต้นบัส I2C (SDA=21, SCL=22) และ PCA9685
  if (!lox.begin()) {
    Serial.println("Failed to boot VL53L0X");
  }
}
