คู่มือการแก้ไข

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

  1. แก้ RB_Nexus_Pins.h เฉพาะเมื่อมี schematic ยืนยัน
  2. แยกการหยุดมอเตอร์ระดับ API ออกจากการเขียนเอาต์พุตภายใน PID
  3. หากเพิ่ม IMU ให้ตรวจ chip identity, หน่วย, เวลา sample และ reset recovery
  4. อัปเดตตัวอย่างและคู่มือให้ตรงกับ signature ใน header
  5. รัน regression tests และ compile ด้วย dependency จริงก่อน push

ห้ามใช้โค้ด dummy เพื่อทำให้ compile ผ่านแล้วระบุว่าทำงานจริง หากยังไม่รองรับให้รายงานข้อจำกัดอย่างชัดเจน
