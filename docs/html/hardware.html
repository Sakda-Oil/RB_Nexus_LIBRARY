ฮาร์ดแวร์

RB_Nexus 0.2.1 · ESP32-WROOM-32 · Arduino-ESP32 3.3.10

RB Nexus V0.1 ใช้ ESP32-WROOM-32, flash 4 MB และ USB-UART CH340 PCA9685 ที่ 0x40 ควบคุมมอเตอร์และ Servo; MCP3208 อ่าน ADC ภายนอก 12 bit

IMU ภายนอกรองรับ MPU6050, MPU9250 + AK8963 และ GY-BNO085 ผ่าน I2C โปรดดู การต่อโมดูล

ข้อจำกัดฮาร์ดแวร์จากรายงานเดิม

รายงานเดิมระบุ M4 ใช้งานได้, M2 ได้ทิศทางเดียว และ M1/M3 มีปัญหา PCB การแก้ซอฟต์แวร์รุ่นนี้ไม่ได้ยืนยันว่าแก้ลายวงจรดังกล่าว ต้องตรวจบอร์ดแต่ละตัวจริง

CAN ต้องมี transceiver และกำหนด TX/RX เอง; pin เริ่มต้นเป็น -1 จึงคืน false ไม่เปิดใช้งานโดยเดา GPIO
